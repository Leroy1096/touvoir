Version UI — Proposition visuelle

Objectif : une image « grande entreprise internationale de sécurité » — premium, sobre, rassurante.

Direction artistiqueStyle & ambiance

  • Univers : technologique et corporate — fonds bleu marine profonds, photographies réelles de caméras, centres de contrôle et techniciens en intervention.
  • Composition : grandes respirations, grille 1 200 px, alignements nets, hiérarchie typographique forte.
  • Finitions : cartes à coins arrondis (16 px), ombres douces teintées bleu marine, survols élégants (élévation + zoom image), micro-animations au défilement.
  • Signal d’action unique : l’orange est réservé aux appels à l’action (devis, prix) — l’œil y revient naturellement sur toutes les pages.

Principes d’interactionRègles UX appliquées

  • Règle des 3 clics : tout contenu est atteignable en 3 clics maximum depuis l’accueil.
  • CTA omniprésents mais uniques : un seul objectif par écran — le devis (orange) ; tout le reste est secondaire (bleu/outline).
  • Feedback immédiat : notifications toast après chaque envoi, erreurs de formulaire en ligne, compteur de résultats du catalogue.
  • Zéro impasse : chaque fiche (service, produit, projet) se termine par une action : devis, prix ou WhatsApp avec message pré-rédigé.
  • Mobile d’abord : cible tactile ≥ 44 px, menu plein écran, appels en 1 touche (tel: / wa.me).
  • Accessibilité : contrastes vérifiés, navigation clavier, focus visibles, textes alternatifs, respect de prefers-reduced-motion.

  • Performance : aucun framework lourd — HTML/CSS/JS natifs, images compressées, chargement paresseux (loading="lazy").
